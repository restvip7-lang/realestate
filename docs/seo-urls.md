# Адреса страниц по ТЗ (ЧПУ)

Источник: ТЗ «новый сайт stay.com.tr — SEO-архитектура, структура и требования к разработке» v1.0, раздел про URL-иерархию.
Схема ТЗ: `/{lang}/{country}/{city}/{district}/{deal}/{type}/{feature}/`.

## Каталог (сделано, PR «Адреса каталога по ТЗ»)
- `/{lang}/turkey/alanya/sale` и `/rent` — весь каталог.
- `/{lang}/turkey/alanya/{район}/sale` — район (slug из коллекции «Районы»).
- `/{lang}/turkey/alanya/[{район}/]sale/{тип}` — тип: `apartments`, `penthouses`, `villas`, `duplex`, `land`, `commercial`, `projects` (`PROPERTY_TYPES[...].path` в `src/lib/catalog.ts`).
- Страницы списка: `…/page-2`, `…/page-3`. `page-1` → 308 на адрес без номера; номер больше числа страниц → 404.
- Остальные фильтры (цена, планировка, до моря, мебель…) и сортировка — параметрами `?…`: такие страницы `noindex`, canonical — на ЧПУ без параметров.
- Неизвестный район, тип или лишний сегмент → 404.
- `/turkey` и `/turkey/alanya` → 308 на `/turkey/alanya/sale`.
- Старые адреса `/sale?district=…&type=…&page=…` и `/rent…` → 308 на ЧПУ, прочие параметры сохраняются.

Код: `catalogBasePath()`, `catalogHref()`, `parseCatalogPath()` в `src/lib/catalog-params.ts`; страница `src/app/(frontend)/[locale]/turkey/alanya/[...path]/page.tsx`. Ссылки на каталог в коде — только через эти функции.

Отличия от ТЗ: адреса без завершающего `/` (как весь сайт; Next.js по умолчанию снимает слэш редиректом). Страна и город пока одни — Турция и Алания (Газипаша — район Алании, как в каталоге).

## Посадочные по признакам и пороги (сделано, PR «Посадочные страницы»)
- Сегмент `{feature}` после типа: `…/sale/apartments/sea-view`. Белый список — `LANDINGS` в `src/lib/catalog-params.ts`:
  - `sea-view` — вид на море; `first-line` — до 100 м до моря; `near-sea` — до 500 м;
  - `with-pool` — открытый или закрытый бассейн (инфраструктура комплекса);
  - `furnished` — с мебелью (в т. ч. частично); `new-build` — новостройка или строится;
  - `citizenship` — только продажа; `pets` — только аренда.
- В пути один признак. Если в фильтре их несколько, в путь идёт первый по порядку списка, остальные — параметрами.
- Признак параметром (`?view=sea`) → 308 на адрес с признаком в пути.
- **Пороги ТЗ** (`INDEX_MIN = 3`, `src/lib/landings.ts`):
  - ≥3 объектов — страница индексируется и попадает в sitemap;
  - 1–2 — страница открыта, но `noindex`, в sitemap её нет;
  - 0 — `noindex`, вместо списка — ссылки на подборку без признака и на ту же подборку по всей Алании.
- Блоки перелинковки внизу каталога («По районам», «По типу», «Популярные подборки») ссылаются только на страницы с ≥3 объектами.
- Матрицу страниц считает `landingMatrix()` по лёгкой выборке `landingSamples()` (только поля признаков, depth 0).
- Расстояние до моря 0 (не указано в CRM) больше не попадает в фильтр «до N м».
