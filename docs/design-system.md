## Что изменилось в v0.2
- Главное — объекты и люди. Координаты, сетка и моноширинные подписи теперь только тихие детали (карта районов, ID).
- H1 28–52 px (было до 72), H2 22–36 px. Основной текст Onest 16–18 px, характеристики 14.5–15 px.
- **Цена графитовая**, 23 px в карточке и 32 px на странице объекта. Коралл только для главных кнопок и бейджа аренды.
- Моноширинный шрифт только для ID. Подписи-«глаза» над заголовками в Onest 13 px, UPPERCASE.
- Сетка объектов 3 / 2 / 1 колонки. На телефоне первые 4 карточки + «Весь каталог».
- Отступы секций 72 px desktop / 48 px mobile.
- Анимация появления включается только при работающем JS (класс `js` на `<html>`), без JS всё видно.
- Фото районов — реальные виды Аланьи, с подписью «иллюстрация».

## Идея: «Навигатор по побережью»
Стиль «современный технологичный», но без холодного PropTech. Сайт устроен как точный инструмент: данные, координаты, карта побережья, цены за м². Каждое число выглядит проверенным. Тёплые фото моря и коралловый акцент не дают сайту стать «банковским».

Фирменные элементы:
- **Линия побережья Аланьи.** Стилизованная SVG-карта с районами встречается в hero, в блоке районов и на лендингах.
- **Моно-подписи с данными:** `36.54°N 32.00°E`, `до моря 350 м`, `ID 1024`. Всё измеримое набирается моноширинным шрифтом.
- **Тонкие линии сетки** вместо теней, тонкие рамки 1px, мало скруглений.

## Цвета (CSS-токены)
| Токен | Значение | Где используется |
|---|---|---|
| `--ink` | `#0E1116` | Основной текст, тёмные секции (hero, футер) |
| `--ink-2` | `#1A1F27` | Карточки на тёмном фоне |
| `--paper` | `#FFFFFF` | Фон |
| `--mist` | `#F4F6F8` | Фон секций, подложки |
| `--line` | `#E3E7EC` / на тёмном `rgba(255,255,255,.12)` | Рамки, сетка |
| `--muted` | `#5B6573` | Второстепенный текст |

| `--sea-deep` | `#00788F` | Hover акцента, текст акцентом на светлом (контраст AA) |

| `--sand` | `#F2E6D8` | Редкий тёплый фон (отзывы, блог) |

Правило: коралл только для действий и цен, максимум 1–2 коралловых элемента на экране.

## Шрифты (все с кириллицей и турецкой латиницей)
- **Unbounded** 500/700: заголовки, логотип, крупные цифры.
- **Onest** 400/500/600: основной текст, интерфейс.
- **JetBrains Mono** 400/500: цены, площади, ID, координаты, подписи-метки (UPPERCASE, трекинг +0.08em).

Шкала: 12 / 14 / 16 / 18 / 22 / 28 / 40 / 56 / 72 px. На мобильных H1 = 34–40 px.
(Вместо Manrope + Inter из первоначального плана: Unbounded + Onest выглядят заметно характернее и тоже поддерживают три языка.)

## Сетка и размеры
- Контейнер до 1320 px, поля 16 px на мобильных и 32 px на десктопе, сетка 12 колонок, gap 24 px.
- Радиусы: 4 px (поля, бейджи), 10 px (карточки), 999 px (чипы).
- Отступы между секциями: 96 px на десктопе, 64 px на мобильных.

## Компоненты
- **Карточка объекта:** фото 4:3, бейджи (вид на море / под гражданство / новостройка), сердечко «в избранное», моно-строка `2+1 · 120 м² · 5 эт. · до моря 700 м`, цена (коралл) и цена за м².
- **Поиск:** вкладки Купить/Аренда, селекты Тип, Район, Комнаты, Бюджет; кнопка показывает число найденных объектов.
- **Чипы-подборки:** иконка + название + счётчик.
- **Переключатели:** язык RU / EN / TR, валюта € $ ₺ ₽ (цены пересчитываются сразу).
- **Мобильная липкая панель:** WhatsApp · Telegram · Позвонить.
- **Метка секции:** `01 — ОБЪЕКТЫ` моноширинным шрифтом.

## Движение
- Появление секций: fade + сдвиг на 16 px, 400 мс, ступенчато. Учитываем `prefers-reduced-motion`.
- Точки районов на карте пульсируют, при наведении раскрывается карточка района.
- Карточка при наведении: фото увеличивается до 1.04, рамка окрашивается в `--sea`.
