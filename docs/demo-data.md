# Демо-данные: что заменить до запуска

По просьбе владельца (25.09.2026) все пустые места в прототипах заполнены **выдуманными** данными. Настоящих контактов, адреса и лицензии пока нет.
В коде они собраны в `KH.COMPANY` (`design/prototypes/assets/data.js`). Когда появятся реальные данные, заменить их там и в местах из таблицы.

**Рабочая версия (этап 2):** те же демо-данные загружаются в базу кнопкой «Загрузить демо-данные» в админке (`src/seed`). Заменять их нужно в админке: «Настройки → Контакты и реквизиты» (там же снять галочку «Данные демо», чтобы убрать плашку), «Компания → Команда», «Компания → Отзывы», «Каталог → Объекты», «Контент → Статьи и новости».
