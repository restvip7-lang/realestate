## Правила
- Координаты районов — OpenStreetMap (Nominatim). Для горных районов объекты ставятся вокруг центра района, для прибрежных — от берега с учётом «до моря».
- Схема побережья на сайте (`KH.COAST`) нарисована по карте владельца, она не в масштабе.
- Цены за м² — демо, реальные нужно получить от агентства.
