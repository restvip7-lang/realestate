# План: сайт агентства недвижимости в Алании (RU / EN / TR)

## Контекст
Агентство недвижимости в Алании (Турция) начинает с нуля: нет бренда, домена и базы объектов. Нужен сайт, который хорошо ранжируется в поиске (Google, Яндекс), удобен для платной рекламы (Google Ads, Яндекс Директ, Meta) и имеет админку, где менеджер по объектам сам добавляет и редактирует объекты.
Образец по структуре и наполнению — restproperty.ru: каталог по типам, районам и тегам, подборки «под гражданство / ВНЖ», карточка с экспертом, проверкой цены и отзывами, статьи и новости, блоки доверия (год основания, лицензии, основатель). Их дизайн перегружен, мы делаем **современный технологичный** стиль: контрастный, строгий, акцент на поиске, карте и фильтрах.
Папка `C:\Users\Manager\Documents\web\RealEstate` пустая. Работать в ней будем **мы вдвоём с ChatGPT**, поэтому нужны git и общие правила для ИИ-агентов.

## Решения
- **Стек:** Next.js 15 (App Router, SSR/ISR) + Payload CMS 3 в одном приложении, TypeScript, PostgreSQL, Tailwind CSS, next-intl.
- **Языки:** RU (основной), EN, TR. Каждый язык живёт на своём URL-префиксе `/ru/`, `/en/`, `/tr/`, прописаны hreflang и x-default.
- **Бренд:** рабочее название придумаем на этапе 0 (3–5 вариантов с проверкой свободных доменов .com и .com.tr). До этого в коде используется переменная `SITE_NAME`.
- **Хостинг:** VPS в Европе (Hetzner) с Docker (Next + Postgres), фото в S3-совместимом хранилище (Cloudflare R2) через CDN. Альтернатива: Vercel + Neon, её обсудим на этапе деплоя.

## Совместная работа с ChatGPT
- `git init` в первый же шаг, коммиты небольшие, у каждого агента своя ветка (`claude/*`, `gpt/*`).
- В корне `AGENTS.md` (его читает Codex/ChatGPT) и `CLAUDE.md` с одинаковыми правилами: стек, структура папок, команды, стиль кода, «не трогать чужую ветку, не переписывать миграции».
- `docs/` — общая база знаний: `brief.md`, `sitemap.md`, `design-system.md`, `content/` (тексты), `seo-keywords.md`. Решения фиксируем там, а не в чате.
- `docs/TASKS.md` — чек-лист задач с отметкой, кто что взял, чтобы не делать одно и то же дважды.

## Структура сайта (URL = SEO-посадочные)
```
/{lang}/                                  Главная
/{lang}/sale/                             Каталог продажи (фильтры + карта)
/{lang}/sale/{type}/                      apartments | villas | penthouses | duplex | land | commercial
/{lang}/sale/{district}/                  mahmutlar | oba | kargicak | kestel | tosmur | cikcilli | avsallar | konakli | center | tepe | gazipasa ...
/{lang}/sale/{type}/{district}/           напр. /ru/sale/villas/kargicak/ — главная SEO-связка
/{lang}/rent/...                          Аренда (долгосрочная), та же схема
/{lang}/collections/{slug}/               Подборки: new-buildings, sea-view, first-line, citizenship, residence-permit,
                                          installment, furnished, resale, best-deals, exclusive
/{lang}/property/{id}-{slug}/             Карточка объекта (ID в URL, поэтому переименование slug не ломает ссылки)
/{lang}/projects/{slug}/                  Новостройки / ЖК (карточка комплекса со всеми квартирами)
/{lang}/districts/{slug}/                 Гид по району: описание, цены за м², инфраструктура, объекты
/{lang}/citizenship/  /residence-permit/  Лендинги: гражданство за инвестиции, ВНЖ
/{lang}/how-to-buy/                       Как проходит покупка: 6 шагов подробно — сроки, документы, расходы, покупка удалённо
/{lang}/services/                         Сопровождение сделки, юр. проверка, ТАПУ, управление арендой, послепродажный сервис
/{lang}/blog/{slug}/  /{lang}/news/       Статьи (SEO-трафик) и новости
/{lang}/about/  /team/  /reviews/  /contacts/  /favorites/  /privacy/
/{lang}/lp/{slug}/                        Рекламные лендинги из админки (без меню, одна форма)
```

Каталог с фильтрами: чистые URL только у комбинаций «тип + район» и подборок. Остальные фильтры идут через query-параметры, у таких страниц `noindex, follow` и canonical на базовую страницу, чтобы не плодить дубли.

## Модель данных (коллекции Payload)
- **Properties**: id (автономер), title/описание (локализуемые), dealType (sale/rent), type, district → Districts, project → Projects, price + currency, pricePerM2 (вычисляется), rooms («2+1»), area, floor/floors, yearBuilt, distanceToSea, distanceToAirport, view (sea/mountain/city), furnished, citizenshipEligible, residencePermitEligible, installment, status (draft/published/reserved/sold/rented/hidden), features[] (бассейн, фитнес, генератор...), gallery (фото с порядком и alt), video/tour3D URL, floorPlans, lat/lng, agent → Team, priceCheckedAt, SEO-поля (metaTitle/metaDescription/ogImage, у каждого поля есть автогенерация по шаблону).
- **Projects** (ЖК), **Districts** (гид + гео-полигон), **PropertyTypes**, **Features**, **Team**, **Reviews**, **Posts** (`kind`: news / article; `category`, `source` — обязателен для новостей о законах, ВНЖ и курсах, `publishAt` с планированием, `reviewedAt`, `pinned`, `relatedProperties`, `relatedDistricts`, переводы RU/EN/TR), **Pages** (конструктор блоков для лендингов), **Leads** (заявки), **Media**, **Users**, **Globals** (контакты, соцсети, курсы валют, шаблоны SEO).
- **Аренда в Properties:** `rentPeriod` (long/short/season), `pricePerMonth`, `pricePerDay`, `deposit`, `minTerm`, `availableFrom`, `utilitiesIncluded`, `petsAllowed`, `advanceMonths`. Переключатель «Продажа / Аренда» в форме меняет набор обязательных полей.
- **Team (сотрудники):** name, role, kind (founder / expert / lawyer), exp, langs, spec, bio, photo → Media, areas → Districts, help[], reviews[] (или связь с Reviews), hidden, order. Объекты (`agent`) и публикации (`author`) ссылаются на сотрудника по ID. Глобал `TeamPage`: заголовок, подзаголовок, цитата основателя, 4 цифры. Прототип: `admin/team.html`, `admin/member-edit.html`.
- **Роли:** admin (всё), editor (объекты, новости и статьи), agent (только свои объекты и свои лиды).
- **Вход в админку (рабочая версия):** встроенная авторизация Payload (коллекция Users): пароль хешируется на сервере, сессия в httpOnly-cookie, `/admin` закрыт от индексации. «Забыли пароль?» — письмо со ссылкой (одноразовый токен, 30 минут) через SMTP-сервис (Resend / Brevo / Yandex 360) с почты на домене kleohomes.com (SPF, DKIM, DMARC). Ограничение попыток входа (блокировка после 5 ошибок), после смены пароля все сессии завершаются, журнал входов. Позже: двухфакторная аутентификация (TOTP) для роли admin.
- **Прототип админки** (согласовать до программирования): `design/prototypes/admin/` — список объектов, форма объекта, список и редактор новостей/статей.
- **Админка для менеджера по объектам:** форма объекта с вкладками «Основное / Фото / Локация (клик по карте) / Описание RU-EN-TR / SEO». Перетаскивание фото с автосжатием в WebP/AVIF и водяным знаком. Кнопки «Дублировать объект», «Перевести описание» (автоперевод RU→EN/TR через API LLM, затем ручная правка). Черновик и предпросмотр до публикации. История версий.

## Карта в рабочей версии
Прототип каталога использует Leaflet и тайлы OpenStreetMap: их правила не разрешают большую нагрузку. В рабочей версии — MapLibre GL + тайлы MapTiler или Stadia (бесплатный лимит, затем платно), кластеры, границы районов полигонами. Координаты объектов хранятся в Properties (`lat`, `lng`), метка ставится в админке на настоящей карте.

## Дизайн-система («современный технологичный»)
- Палитра: графит `#0E1116`, белый, холодный серый `#F4F6F8`, акцент «средиземноморский циан» `#00A3C4`, второй акцент для CTA и цен — тёплый коралл `#FF6B4A`. Тёмная тема для hero и футера.
- Шрифты: Manrope (заголовки и UI) + Inter (текст), оба с кириллицей и турецкими буквами.
- Сетка 12 колонок, радиусы 12px, тонкие границы вместо теней, числа моноширинные (цены, площади).
- Ключевые компоненты: hero с поисковой строкой (тип / район / бюджет / комнаты); каталог в режиме «сплит»: список + интерактивная карта (MapLibre + кластеры); карточка объекта (слайдер, бейджи «вид на море», «под гражданство», цена в выбранной валюте, цена за м²); липкая панель CTA на мобильных (WhatsApp / Telegram / звонок); сравнение и избранное (localStorage); калькулятор расходов на покупку (налог на ТАПУ 4%, услуги, страховка DASK).
- Mobile-first: больше 70% рекламного трафика приходит с телефонов.

## SEO
- SSR/ISR у всех публичных страниц, `generateMetadata` из CMS, canonical, hreflang, `sitemap.xml` (разбит по языкам и типам), `robots.txt`, `llms.txt`.
- JSON-LD: `RealEstateAgent` + `LocalBusiness` (адрес в Алании), `RealEstateListing`/`Offer` на карточке, `BreadcrumbList`, `ItemList` в каталоге, `FAQPage` на лендингах, `Article` в блоге, `Review`/`AggregateRating`.
- Core Web Vitals: `next/image`, AVIF, lazy-загрузка карты, шрифты через `next/font`. Цель — Lighthouse 90+ на мобильных.
- Проданные объекты не удаляются: страница остаётся с бейджем «Продано» и блоком похожих объектов, так ссылочный вес не теряется. Снятые с публикации отдают 301 на каталог района.
- Внутренняя перелинковка: карточка ↔ район ↔ ЖК ↔ подборки, блок «Похожие объекты».
- Google Business Profile, Яндекс Бизнес, Search Console, Яндекс Вебмастер.

## Реклама и аналитика
- GTM + GA4 + Яндекс Метрика (с вебвизором) + Meta Pixel. События: отправка формы, клик по WhatsApp / Telegram / телефону, просмотр карточки, добавление в избранное.
- Server-side конверсии: Meta CAPI, офлайн-конверсии Google Ads из статусов лидов.
- UTM-метки и gclid/yclid сохраняются в лид, чтобы видеть, какая кампания приносит сделки.
- XML-фиды объектов: Google Ads (Real estate), Яндекс Недвижимость (YRL), Meta Catalog, чтобы крутить динамический ремаркетинг.
- Конструктор лендингов в админке (`/lp/*`): блоки hero / объекты / форма / FAQ без правки кода.
- **Заявки (решение владельца 25.09.2026):** на запуске приходят письмом на e-mail агентства: имя, телефон, способ связи, ID и ссылка на объект, страница, UTM-метки. Письма отправляет сервер через SMTP-сервис (Resend / Brevo). Telegram-бот для менеджеров подключим позже. Копия заявки сохраняется в базе (коллекция Leads), чтобы письмо не потерялось и чтобы считать конверсии рекламы. Позже можно подключить CRM (amoCRM или Bitrix24) через вебхук.
- Cookie-баннер с согласием (Consent Mode v2).
