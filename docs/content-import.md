# Новости, отзывы и услуги из Stay Property

Статус: **готово** (09.10.2026). На сайте появятся после слияния PR и нажатия кнопки в админке (или ночного запуска).

## Источник
- Сервис контента агентства: `https://admin.stayproperty.com`, адрес сервера 62.169.23.237. Там же админка Stay Property. Описание API владелец прислал файлом `BACKEND_API_RU.md`.
- **Чтение без авторизации:** `GET /api/content/{news|reviews|services}?page=&limit=100`, заголовок `Accept: application/json`.
  - Список отдаёт только опубликованные записи (`enabled=true`), сортировка по `updated_at`.
  - Вход в их админку и пароли сайту **не нужны**. Если там включат токен (`MIRROR_API_TOKEN`), его кладут в `CONTENT_API_TOKEN` (Vercel).
- **Поля записи:**
  - `id` (`news-…`, `seed-news-01`…), `title`, `excerpt`, `body` (обычный текст, иногда HTML), `category`, `location`, `image` (URL на `eu2.contabostorage.com`);
  - `published_at` — сейчас только год `"2026"`;
  - `created_at`, `updated_at`;
  - `translations.{ru,en,tr,sr,fa}` с полем `_origin` (`editor` — написано редактором, `ai` — перевод их сервиса).
- На 09.10.2026: **21 новость, 7 отзывов, 20 услуг.** Переводы ru/en/tr есть почти везде, поэтому свой автоперевод не нужен.

## Как работает
- **Код:**
  - `src/lib/content-api.ts` — клиент, только GET;
  - `src/lib/content-text.ts` — очистка текста;
  - `src/lib/content-sync.ts` — синхронизация.
- **Запуск:**
  - кнопка «Обновить новости, отзывы и услуги» на главной админки (только администратор, `POST /next/content-sync`);
  - Vercel Cron в 02:47 UTC (`vercel.json`, `GET /next/content-sync` с `CRON_SECRET`, та же переменная, что у Stay Portfolio);
  - локально `npm run content:sync` (в песочнице Claude — с `NODE_USE_ENV_PROXY=1`).
- **Скорость:** первый запуск 48 записей — около 5 с локально. Повторный перечитывает только записи, у которых изменился `updated_at`.

| Stay Property | У нас | Что приходит оттуда | Что остаётся нашим |
|---|---|---|---|
| news | `posts`, тип «Новость», рубрика «Рынок и цены» | заголовок, лид, текст (ru/en/tr), обложка; дата — из `created_at`, а если в `published_at` полная дата — из неё | рубрика, автор, публикация, SEO, закрепление, связи |
| reviews | `reviews` | имя, страна, текст (русская версия: поля отзыва не переводятся), дата из `created_at` | «Показывать на сайте», услуга, сотрудник, оценка |
| services | новая коллекция `services` | название, кратко, текст (ru/en/tr), обложка, раздел (бесплатные / услуга по категории) | публикация, порядок, SEO |

## Правила
- **Сразу на сайт** (решение владельца). Ненужную запись менеджер снимает с публикации в нашей админке. Синхронизация её обратно **не включает**: статус публикации берётся только при создании.
- **Запись пропала из сервиса** (удалена или выключена там) → у нас снимается с публикации (новость — в черновик, отзыв и услуга — «не показывать»). **Не удаляется.**
- **Отзывы из Stay Property без оценки:** звёзды не показываем. Средняя оценка и распределение на `/reviews` считаются только по отзывам с оценкой. Оценку не придумываем.
- **Обложки** показываются прямо из хранилища Stay Property (`remoteCover`, без оптимизатора Vercel), к нам не копируются. Если загрузить свою обложку в админке, на сайте будет она.
- **Адреса страниц (slug)** создаются из русского заголовка один раз и потом не меняются. При совпадении к адресу добавляется хвост из ID.
- **Услуга только с турецким текстом** создаётся скрытой: иначе на русской и английской версии был бы турецкий текст.

## Очистка текста (`content-text.ts`)
- **Абзацы:** длинная строка без абзацев (почти все новости) делится на абзацы по 3–4 предложения.
- **Структура:**
  - строки «- …» становятся списком;
  - короткие строки без точки в конце — подзаголовками;
  - повтор заголовка в начале текста убирается.
- **Услуги, перенесённые со старого сайта:**
  - буквальные `\n`, `**` и пустые markdown-ссылки убираются;
  - обрывки нумерации («-», «1») превращаются в подзаголовок пункта;
  - **карточки менеджеров в конце** (имя, «Телефон:», WhatsApp, e-mail, языки) и подписи кнопок («Заказать обратный звонок», «Задать вопрос») отрезаются.
- Лид, повторяющий начало текста, над текстом не показывается (новости и услуги). В карточках и описании для поисковиков он остаётся.

## Что заметили в данных (владельцу решить)
- **Тестовые записи на сайте:** «Тестовые новости.», «Тестовый отзыв для тестового клиента.», «Тестовая услуга.». Снять с публикации здесь или выключить там.
- **Новости не про Турцию:** 7 из 21 — Дубай/ОАЭ, Северный Кипр, Бали.
- **Чужие бренд и имена в текстах:** «Stay Property», «STAY PROPERTY», управляющая «Виктория» — в отзывах, услугах и 7 новостях. Сайт называется Kleo Homes.
- **Нет точной даты новости:** в `published_at` только год. На сайте дата добавления записи в сервис (у 20 новостей — 11.09.2026). Если там вписать полную дату (`2026-10-06`), сайт её подхватит.
- **Ошибки переводов в сервисе:**
  - у услуги «Обмен» турецкая версия на самом деле на немецком;
  - у отзыва «Гюльнар» страна в русской версии по-английски.
- «Transfer» есть только по-турецки — на сайте скрыта.
