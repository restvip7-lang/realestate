# Новостройки (/projects)

Статус: **готово** (20.10.2026). Решение владельца: сайт готовим к продаже, раздел новостроек делаем первым.

## Что это
- **Раздел** `/{ru|en|tr}/projects` — проекты застройщиков: объекты с типом «Новый проект» (`type: 'project'`). В каталоге Stay их 171 из 1204.
- **Коллекции ЖК нет.** В Stay нет связи «комплекс → квартиры», поле «Комплекс» у объектов пустое. Поэтому проект Stay и есть карточка комплекса:
  - планировки «1+1, 2+1»;
  - площади «от–до»;
  - цена «от»;
  - год сдачи;
  - инфраструктура комплекса.
- **Отдельные квартиры в новостройках** (тип «Квартира», состояние «новое» или «строится», их около 530) остаются в каталоге: `/sale?new=1`. На них ведёт ссылка из раздела.
- **Свой проект** менеджер добавляет в админке как обычный объект с типом «Новый проект», и проект сразу появится в разделе (`docs/admin-guide.md`).

## Страница
- **Шапка:**
  - число проектов;
  - минимальная цена в выбранной валюте;
  - число районов;
  - диапазон лет сдачи.
- **Фильтры** (адрес страницы, без JavaScript):
  - год сдачи (`?when=2026`);
  - «Под гражданство» (`?cit=1`);
  - район (`?district=`), в списке только районы с проектами;
  - бюджет до (`?max=`);
  - сортировка (`?sort=cheap|expensive|soon`);
  - страницы по 24 (`?page=`).
- **Карточка** (`ProjectCard`):
  - «Сдача 2026»;
  - значок «Гражданство»;
  - планировки, площади, расстояние до моря;
  - цена «от»;
  - «Рассрочка», если она заполнена;
  - число удобств в комплексе.
- **Внизу страницы:**
  - FAQ из 6 вопросов: оплата, рассрочка, ТАПУ, комиссия, гражданство и ВНЖ, задержка сдачи;
  - SEO-текст и ссылки «Новостройки в <районе>».
- **Тексты** написал Claude, они черновые. Перед запуском их должен сверить юрист: суммы для гражданства и ВНЖ, порядок выдачи ТАПУ, «услуги бесплатны — платит застройщик» (см. `docs/demo-data.md`).
- **SEO:**
  - `pageMeta`, canonical `/projects`;
  - страницы с фильтрами — noindex;
  - JSON-LD: `BreadcrumbList`, `ItemList`, `FAQPage`;
  - страница есть в `sitemap.xml` и `llms.txt`.

## Срок сдачи
- Год сдачи — поле «Год» (`year`), в Stay это `year_built`. Сдан ли дом, Stay не сообщает: «Сдан» / «Строится» не пишем, показываем только «Сдача 2025».
- Если появятся точные данные (дата сдачи, статус стройки, застройщик), их можно добавить полями объекта или отдельной коллекцией ЖК (миграция).

## Где ещё
- **Страница проекта** — обычная страница объекта, для типа «Новый проект» на ней:
  - крошки «Новостройки › район»;
  - «Срок сдачи» вместо «Года постройки»;
  - блок «Планировки» чипами;
  - ссылка «Новостройки в <районе>»;
  - похожие объекты — только другие проекты.
- **Ссылки на раздел:**
  - пункт «Новостройки» в меню;
  - футер;
  - чип «Новостройки» на главной;
  - ссылка в SEO-блоке страницы района (если там есть проекты).
